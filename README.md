# PostIt

PostIt is a full-stack web application that allows users to create, view, update, and delete personal posts through a simple and responsive interface.

The project is built using React for the frontend and FastAPI for the backend, with MySQL used for data storage. User authentication is implemented to ensure that users can securely manage their own posts.

## Features

* User registration and login
* Secure authentication using tokens
* Create new posts
* View existing posts
* Update posts
* Delete posts
* Responsive and clean user interface
* Backend API built with FastAPI
* MySQL database integration

## Tech Stack

### Frontend

* React
* Vite
* Axios
* CSS

### Backend

* FastAPI
* Python
* SQLAlchemy
* MySQL
